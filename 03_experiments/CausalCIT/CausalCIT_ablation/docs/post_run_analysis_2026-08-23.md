## 1. 修 C: 语义环境切分验证 (negative result)

| 数据集 | pl | uniform (full_v2_fixed) | semantic (season) | Δ |
|--------|----|------------------------|-------------------|---|

| electricity | 192 | 0.17063 | 0.175135 | **+2.64%** |
| weather | 96 | 0.14549 | 0.147751 | **+1.55%** |
| weather | 192 | 0.19250 | 0.192786 | +0.15% |
| weather | 336 | 0.22445 | 0.224585 | +0.06% |

**结论**: 5/5 组语义切分都不如均匀切分 → 修 C **止损**。与方案 1 对应
("语义信息量 5/17 无预测力") 一致: 数据上有信息 ≠ 训练时门控能用上 (batch 内
每环境样本数 ~8×patch_num, HSIC 估计方差大; 且语义组聚合不优化预测目标)。

**论文取舍**: 不报告语义切分方案; 改报告 "负结果 + 原因分析" 作为诚实边界。

## 5. 高维门控诊断 ⭐

**诊断图 (pl96, 跨 seed 均值)**:
- capacity_match: off_std=0.004, collapse 0%
- full_v2: off_std=0.047, collapse 0%, **batch_dep=0.34 (跨 batch 依赖, 不稳定)**
- **full_v2_fixed: off_std=0.062, collapse 0%, batch_dep≈0 (好)**
- gate_prior_only: collapse 100% (坍缩)
- no_env: off_std=0.195, batch_dep=0.01

**full_v2_fixed 达到最佳平衡**: 结构化 (off_std 高) + 无坍缩 + 跨 batch 独立。
修复 A+B 正是为消除 full_v2 的 batch 依赖 (cca0.34) 而设计的, 效果直接验证。

**electricity 热图 (pl96, seed42, 50/321 通道子采样)**: 清晰**块对角结构**
(3-4 个块, 每块 ~10-15 通道), 与电力客户聚类一致 → 门控选到了真实依赖结构。
off-diag std=0.1043。

**结论**: 门控 "识别对了", 且修复版下 "跨 batch 也稳定"。
