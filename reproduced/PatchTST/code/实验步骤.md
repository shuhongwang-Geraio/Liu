### 六、注意事项

1. 当前环境无 GPU，会自动使用 CPU 训练，速度较慢但结果一致
2. 早停机制 `patience=20` 会在验证集 loss 连续 20 个 epoch 不下降时自动终止，通常 30-50 个 epoch 就收敛
3. `--num_workers 0` 是 Windows 下的必要设置，避免多进程报错
4. 如果想节省时间只验证可行性，可以把 `--train_epochs` 降到 10-20
