# 给 Survey Agent 的调研提示词

## 背景（可直接粘贴给 agent）

我在探索一个多变量时间序列预测的新方法，核心思路是：

> 借鉴 StableNet（CVPR 2021）的统计独立性度量思想（基于 Random Fourier Features 的 HSIC 独立性检验），设计一个**可逆的通道解耦变换** W，将原始多变量序列 X（形状 [T, N]，N个通道）映射到一个"隐通道"空间 Z = X·W，并在训练中用独立性正则（如 RFF-HSIC）鼓励 Z 的各维度统计独立；然后借鉴 PatchTST（ICLR 2023）的做法，对每个隐通道用共享参数的 Channel-Independent backbone（Patch + Transformer）独立预测，得到隐通道预测 Ẑ；最后通过逆变换 W⁻¹（若 W 正交则为 Wᵗ）将 Ẑ 映射回原始通道空间，得到最终预测 Ŷ。

一句话即：**解耦（独立性约束的可逆变换）→ 独立预测（CI backbone）→ 还原（逆变换）**。

目的是结合 CI 策略的鲁棒性（不学脆弱的虚假跨通道相关）与 CD 策略的信息完整性（可逆变换理论上不丢信息），并用独立性检验替代简单的相关系数/协方差，处理非线性依赖。

### 子问题 2：独立性约束/度量方式在时序模型中的应用
